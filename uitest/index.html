ui-drift 수동/시각 테스트

  • editor.html - 편집 모드 (드래그/리사이즈/터치/반응형/JSON). 리사이즈 핸들은 ?handles=se,sw,e,w,s 쿼리로 선택
  • multi-container.html - 여러 컨테이너 (DriftManager: 등록/해제, 활성 컨테이너, 공통 팔레트, 전체 JSON 저장/복원, 이벤트)
  • sortable.html - Sortable (목록 정렬, handle, 그룹 이동, clone, 줄바꿈, 자동 스크롤)
  • viewer.html - editor 에서 저장한 레이아웃(localStorage)을 읽어 표시
  • viewer-fit.html - Viewer fitHeight (높이 100% 를 행 수로 나눔, 767px 이하는 한 줄 적층. 폭/최소 행 높이 조절)
  • example/fit.html - 높이 100% Viewer 예제 (JavaScript 없음, npm run example 으로 생성)
  • example/viewer.html - Viewer (JavaScript 없이 CSS 만 사용, npm run example 으로 생성)
